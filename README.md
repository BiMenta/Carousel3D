# 视频参考旋转木马

参考：04_CarouselPhotoBooth.mp4，26.04 秒。主要观察开场俯视、6–9 秒坐骑近景和侧面场景。

交付：carousel.blend，build_carousel.py，carousel_preview0001.png。

模型包含：三层红金圆形基座、64 片放射木地板、12 面雕饰中柱、32 片红白帐篷顶、12 组波浪形灯牌、金色立杆、6 匹不同配色马鞍的木马、1 个天鹅座舱、1 个红金马车座舱。共 1405 个对象（包含曲线、灯光和父级控制器）。

动画：24 fps，播放 1–240 帧，10 秒一圈；第 241 帧与第 1 帧重合。6 匹木马分别按不同相位升降，每 5 秒一个周期，振幅 0.25 米。通过父级旋转与坐骑高度驱动器控制。顶棚保持固定。

打开工程后按空格播放。旋转控制器名为 ANIMATION • rotating platform；各坐骑父级名为 Horse 00–05 • animated mount。

模型为根据视频可见结构进行的风格化重建。马匹采用程序化融合雕塑几何，非视频中的原始角色资产；未制作视频人物、周边帐篷及摄影棚。材质为程序化材质，无外部贴图依赖。
